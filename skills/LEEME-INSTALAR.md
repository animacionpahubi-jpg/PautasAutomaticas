# Skills de Pahubi — cómo instalarlas en un entorno nuevo

Cada carpeta dentro de `skills/` es una skill: contiene un archivo `SKILL.md` (con nombre y descripción arriba y las instrucciones abajo).

**Claude (claude.ai / Cowork):** Configuración → Capacidades → Skills → subir cada carpeta comprimida en .zip (cada .zip debe contener la carpeta de la skill con su SKILL.md).
**Claude Code:** copiar cada carpeta a `~/.claude/skills/<nombre>/SKILL.md` (o a `.claude/skills/` dentro del proyecto) y reiniciar la sesión.
Si no hay forma de instalarlas, pegar su contenido como instrucciones del proyecto: el texto completo también está en la pestaña "Skills — texto completo" del documento guía.
